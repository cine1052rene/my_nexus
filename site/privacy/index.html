4. 개인정보의 삭제 방법

이용자는 아래 두 가지 방법 중 하나로 계정과 모든 데이터를 삭제할 수 있습니다.

  • 앱 내에서 삭제 — 앱 설정 탭 → "계정 삭제"
  • 웹에서 삭제 — 앱을 삭제한 경우에도 my-nexus-hub.web.app/delete-account 에서 Google 계정으로 로그인 후 삭제할 수 있습니다.

삭제 요청 시 Google 계정 인증 정보를 제외한 저장된 링크·클립·일정·설정 데이터베이스 항목이 서버에서 재귀적으로 영구 삭제되며, 복구할 수 없습니다.
